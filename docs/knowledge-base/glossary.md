# Knowledge Base — Glossary

Term definitions, one entry per domain term introduced by an article. Add a term here
whenever a new KB article introduces domain vocabulary.

## Call Forwarding

- **Unconditional / always forwarding** (`**21*` / `*21*`) — forwards every call
  regardless of line state; takes precedence over all conditional forwarding rules.
- **Conditional forwarding** (`**67*`/`**61*`/`**62*` family) — forwards only on
  busy / no-answer / unreachable; inactive whenever unconditional forwarding is active.
- **3GPP TS 22.030** — the technical standard defining the GSM supplementary service
  codes used for call forwarding; the reason the same codes work across every carrier
  and country.
- **MVNO** (Mobile Virtual Network Operator) — a carrier that resells mobile service
  on another operator's network (the `Network` column on each country page) rather
  than owning its own infrastructure.
- **Deviazione di chiamata** (Italian) — call forwarding.
- **Transfert d'appel** (French) — call forwarding.
- **Rufumleitung** (German) — call forwarding.
- **Desvío de llamadas** (Spanish) — call forwarding.
- **Doorschakelen** (Dutch/Flemish) — call forwarding.
- **Renvoi d'appel** (French, Belgium/Luxembourg) — call forwarding.
