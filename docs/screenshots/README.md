# Screenshots

This folder is intentionally empty in the public repository — the original
walkthrough recording was made against pre-demo data and has been removed.

To record a fresh walkthrough of the six workspace tabs (Assistant, Documents,
Sources, Sync, Governance, System Health) against the current demo data:

1. Run `npm run dev` and open `http://localhost:3000`.
2. Sign in as an Administrator so every tab is visible.
3. Capture at ~1280×800 (light mode) and save the GIF/PNGs here, e.g.:

```markdown
![Assistant](docs/screenshots/assistant.png)
```

Then reference them from the root [README](../../README.md).
